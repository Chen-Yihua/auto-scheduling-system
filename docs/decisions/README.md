# 架構決策紀錄（ADR）

記錄「之後的人會想問為什麼不用 X」的決定。一個決定一個檔案，檔名 `NNNN-<簡短名稱>.md`，編號遞增、不重複使用。

決定被推翻時不要刪掉舊檔：新增一份新的 ADR，並把舊檔的狀態改成「已被 NNNN 取代」。

## 格式

```markdown
# NNNN. 標題

- 狀態：已採用 | 已被 NNNN 取代
- 日期：YYYY-MM-DD

## 背景
遇到什麼問題、有什麼限制。

## 決定
做了什麼選擇。

## 放棄的做法
考慮過但沒選的做法，以及沒選的原因。

## 影響
這個決定帶來的代價和之後要遵守的規則。
```
