# issue #47 Prettier 分號風格規格審查

- 狀態：已核准
- PR：#136

## 審查摘要

規格經 3 輪審查；第 1 輪修正連結與驗證命令，第 2 輪確認保留 `semi: true`、將既有程式統一為分號風格及分開 commit，第 3 輪修正 AC4 與設定檔不修改的矛盾。

## 發現與處理

| 發現 | 分類 | 處理 | 決定者 |
|---|---|---|---|
| 第一輪規格中的連結與前端命令不可直接執行 | 一般操作就會遇到的錯 | 修正為 scratchpad 可解析的連結與 `cd frontend && npm run ...` | 開發者 |
| 第一輪範圍未界定其他 Prettier 格式差異 | 規格沒寫某個情境該怎麼做 | 新增只納入分號直接造成差異、排除其他格式規則差異 | 開發者 |
| 第三輪 AC4 表述與不修改設定檔矛盾 | 規格內容互相矛盾或沒有依據 | AC4 改為格式變更獨立 commit且不修改 `.prettierrc` | 開發者 |

## 結論

第二輪與第四輪最終重審均確認無阻擋問題；規格已核准並開始實作。
