# 術語表

這個專案的產品用詞：使用者看得到的概念用哪個名稱、指的是什麼。

**今日卡片**：
首頁的卡片，列出已逾期的任務，以及排進今天排程時段的任務。
_避免_：今日清單、今天的任務列表、今日行程

**已逾期**：
還沒完成的任務，截止日那一天（使用者瀏覽器時區）已經結束，或排程時段的結束時間已過。
_避免_：過期、錯過排程時段、時段已過、過期任務

**任務管理頁**：
標題列「任務管理」連到的頁面（`/tasks`），列出所有來源的任務。
_避免_：任務頁、完整任務清單

**排程狀態**：
任務有沒有寫進 Google 日曆：「已排程」或「未排程」。和完成狀態（未開始、進行中、已完成）是兩件事。
_避免_：排程進度
